# Makeup By Intan Berlianda — Website MUA Profesional

Website profesional untuk jasa Makeup Artist berbasis di Bekasi, dibangun dengan HTML, CSS, dan JavaScript murni. Semua data disimpan menggunakan **LocalStorage** — tidak butuh backend atau server!

## 🌐 Demo
Upload ke GitHub Pages dan akses langsung via browser.

## 📁 Struktur File
```
makeup-by-intan/
├── index.html          → Website utama (publik)
├── admin.html          → Dashboard admin
├── css/
│   ├── style.css       → Stylesheet utama
│   └── admin.css       → Stylesheet admin
├── js/
│   ├── app.js          → Logic website publik
│   └── admin.js        → Logic admin dashboard
└── assets/
    ├── img/            → Folder untuk gambar
    └── icons/          → Folder untuk icon
```

## 🚀 Deploy ke GitHub Pages

1. Buat repository baru di GitHub
2. Upload semua file ke repository
3. Buka **Settings → Pages**
4. Source: pilih **main branch → / (root)**
5. Tunggu beberapa menit, website akan live!
